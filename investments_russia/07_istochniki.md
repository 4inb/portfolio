## Глоссарий
| Термин | Значение |
|---|---|
| YTM | Доходность к погашению — полная доходность облигации при держании до конца |
| Купон | Процентный платёж по облигации |
| НКД | Накопленный купонный доход — доплата продавцу при покупке облигации |
| Дюрация | Чувствительность цены облигации к изменению ставки |
| Оферта | Дата, когда эмитент может досрочно выкупить облигацию / изменить купон |
| Амортизация | Возврат номинала частями до погашения |
| БПИФ | Биржевой паевой фонд — корзина бумаг одной покупкой |
| TER | Годовые расходы фонда в % от активов |
| ФДР | Фонд денежного рынка (РЕПО с ЦК, ≈ ключевая ставка) |
| RUONIA | Ставка межбанковских кредитов «овернайт» |
| ИИС-3 | Индивидуальный инвестиционный счёт с вычетом на взнос и на доход |
| ЛДВ | Льгота долгосрочного владения (3+ года — без НДФЛ) |
| P/E | Цена / прибыль — сколько лет прибыли «стоит» компания |
| Ребалансировка | Возврат долей портфеля к целевым |
| MCFTR | Индекс МосБиржи полной доходности (с реинвестированием дивидендов) |
